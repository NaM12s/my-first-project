# Simple Accounting Web App

This project provides a minimal accounting system built with PHP and MySQL. It demonstrates basic features such as user login, account management, journal entries, and placeholder pages for reports.

## Setup
1. Create a MySQL database named `accounting_db` and import the schema from `db.sql`.
2. Update database credentials in `webapp/includes/config.php` if necessary.
3. Place the `webapp` folder in a PHP-enabled web server directory.
4. Access `index.php` through your browser.

## Features
- User authentication
- Dashboard with navigation links
- Manage accounts (add/list)
- Record journal entries
- Placeholder for financial reports

This is a lightweight starting point and can be extended for full accounting functionality.
